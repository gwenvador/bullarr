Bullarr est un Sonarr pour les BD et les comics : il surveille les nouveautés, télécharge les albums qui manquent à vos séries et tient vos fiches à jour grâce à Bédéthèque.

1 Installation

Bullarr tourne dans Docker, avec une base SQLite : rien d'autre à installer. Le guide complet est dans le README.

  1. Clonez le dépôt : git clone https://github.com/gwenvador/bullarr.git
  2. Copiez le modèle : cp docker-compose.example.yml docker-compose.yml
  3. Adaptez les volumes : le dossier de votre bibliothèque (/BD) et vos dossiers d'import.
  4. Créez le fichier .env avec une clé secrète, une longue chaîne aléatoire : 
    echo "SECRET_KEY=$(python3 -c 'import secrets; print(secrets.token_urlsafe(48))')" > .env
  5. Démarrez : docker compose up -d, puis ouvrez http://localhost:4000.

2 Premier démarrage

  1. Dans Configuration, ajoutez une bibliothèque en indiquant son dossier racine.
  2. Lancez le scan : Bullarr relève les séries et les tomes présents sur le disque.
  3. Rattachez chaque série à sa fiche Bédéthèque : résumé, auteurs, éditeur, couverture et liste des tomes parus.
  4. La page Vérification liste ensuite les séries sans fiche et les fichiers mal nommés.

3 Fonctions

📚 Bibliothèque

  • Trois vues : affiches, aperçu (une ligne par série) et tableau.
  • La recherche du haut de page trouve les titres et les tags.
  • La fiche d'une série montre les tomes possédés et manquants.

📡 Surveillance

Bullarr lit les flux RSS, EBDZ et Telegram, repère les nouveaux albums de vos séries et télécharge ceux qui vous manquent.

🧭 Enrichir

Des idées pour compléter la collection : indispensables, Panthéon, thèmes, Top 100, sorties BDGest, ou tous les albums d'un auteur.

📖 Lecteur de BD

CBZ, CBR et PDF dans le navigateur : double page, zoom, miniatures, plein écran. ? affiche les raccourcis.

✏️ Renommage et métadonnées

Fichiers et dossiers renommés selon un modèle, à partir de la fiche Bédéthèque. Le ComicInfo.xml est écrit dans chaque archive.

🔔 Notifications

Telegram ou ntfy à chaque import, validation ou tome surveillé (Configuration → Notifications). Le message renvoie vers la fiche de la BD.

✨ Upscaling

Repère les tomes en basse définition et les passe en HD, sur le serveur ou à la volée dans le lecteur. Voir Upscaling.

📑 Lectures

Suivi → Lectures : ce que vous avez lu, avec export et import CSV. Imports et actions sont, eux, dans Suivi → Historique.

4 Tags et listes

  • Tags (thèmes, lieux, époques…) : fenêtre Tags de la fiche, + pour ajouter, × pour retirer. L'IA peut les créer pour vous (section suivante).
  • Un clic sur un tag affiche toutes les séries qui le portent. La vue tableau a une colonne Tags filtrable.
  • Listes « À lire plus tard » et « Favori » : menu Actions de la fiche. Le menu Listes de la bibliothèque les affiche.

5 Import automatique

Bullarr surveille vos dossiers de téléchargement (aMule, torrents, Telegram, web). Chaque fichier qui arrive est reconnu (série, tome), converti en CBZ si besoin et rangé dans la bonne série. La page Activités suit les téléchargements en cours (pause, passage en premier) et liste les fichiers que Bullarr n'a pas su ranger seul.

6 Bullarr et IA

Tags par IA

Choisissez un fournisseur dans Configuration → IA :

  • aiautotagging.com (par défaut) : gratuit, sans clé ni compte.
  • Claude, Gemini, ChatGPT, OpenRouter, Groq : collez votre clé API, puis « Tester ». ↻ charge la liste des modèles.
  • LLM local (Ollama, LM Studio, llama.cpp, vLLM) : indiquez l'adresse du serveur.

Cochez des IA de secours : si un fournisseur échoue (quota, panne), le suivant prend le relais. Les consignes envoyées à l'IA sont modifiables. Ensuite :

  • Créer les tags : pour les séries sans tags, ou pour toutes. L'IA lit la fiche et réutilise vos tags existants. Elle ajoute, ne retire rien.
  • Normaliser les tags : l'IA propose de fusionner les doublons (« ww2 », « seconde-guerre-mondiale »). Rien ne change avant votre validation.
  • Nouvelles séries : une option tague chaque série dès son ajout.
Seuls le titre, les auteurs, le genre, l’année, l’origine, le résumé et les tags sont envoyés, jamais les fichiers. Avec votre propre clé, les appels sont facturés par le fournisseur. Chaque traitement est visible dans l'historique.

Serveur MCP

Le serveur MCP (adresse /mcp de votre instance) permet à Claude ou à un autre assistant de fouiller votre bibliothèque : « J'ai un polar noir avec des animaux ? ». Il peut aussi changer les tags et les listes.

OutilRôle
search_seriesChercher par mots, tags et année.
get_seriesLire la fiche d'une série.
list_tagsLister les tags et le nombre de séries pour chacun.
set_series_tagsRemplacer les tags d'une série.
set_reading_listsGérer « à lire plus tard » et les favoris.

Activer le serveur

  1. Ajoutez BULLARR_MCP_TOKEN= suivi d'une chaîne aléatoire dans le .env, puis redémarrez. Sans ce jeton, le serveur MCP est désactivé.
  2. Déclarez le serveur dans votre assistant, par exemple Claude Code :
claude mcp add --transport http bullarr https://<votre-bullarr>/mcp \
  --header "Authorization: Bearer <BULLARR_MCP_TOKEN>"

Les autres clients prennent la même adresse et le même en-tête Authorization: Bearer.

Le serveur ne supprime rien et ne touche à aucun fichier. Gardez le jeton pour vous. Un assistant hébergé sur internet (ChatGPT, claude.ai) ne joint votre Bullarr que s'il est accessible depuis internet.

7 API

Tout ce que fait l'interface passe par une API HTTP/JSON. Envoyez une clé dans l'en-tête X-Api-Key :

  • clé d'administration : Configuration → Login → Accès API, tous les droits ;
  • clé personnelle : Mon profil, limitée aux droits du compte.

La page /api/docs de votre instance liste les routes ; docs/API.md les détaille avec des exemples curl et Python.

8 Application Android

Bullarr dans la poche : bibliothèque, recherche, téléchargements, import et réglages. Elle lit vos albums (webtoon, sens manga, double page en paysage), les garde sur le téléphone pour lire hors ligne et reçoit les notifications par ntfy.

  1. Installez-la au choix : dépôt F-Droid, Obtainium (mises à jour signalées) ou APK direct.
  2. Indiquez l'adresse du serveur (par exemple http://192.168.1.10:4000), puis connectez-vous : identifiant et mot de passe, SSO ou clé API.

9 Upscaling

Les BD numérisées il y a longtemps ont souvent des pages de 1600 px ou moins, floues sur un grand écran. L'upscaling les agrandit deux fois avec un réseau de neurones fait pour le dessin : traits nets, aplats propres, artefacts JPEG effacés.

Repérer les albums concernés

Chaque couverture porte une pastille LD, SD ou HD, et la fiche d'une série indique combien de ses tomes sont en basse définition. Le seuil (1600 px par défaut) se règle dans Configuration → Upscaling.

Améliorer un album

  • Pour lire : le bouton HD du lecteur améliore les pages à la volée, dans le navigateur. Le fichier ne change pas.
  • Pour de bon : Upscaler en HD dans la molette d'un tome ou d'une série, ou la page Actions → Upscaling pour en traiter plusieurs. Le fichier est remplacé par sa version HD ; l'original est gardé et Restaurer la version SD le remet en place.

Comptez de quelques minutes à plus d'une heure par album : le serveur calcule sur le processeur, un tome à la fois.

Choisir le modèle

Huit modèles, Real-ESRGAN et Real-CUGAN. Real-ESRGAN rapide convient presque toujours ; Real-CUGAN affine les traits de la BD franco-belge, en plus lent. Sur la page Upscaling, Modèle et comparaison les essaie tous sur un extrait de vos pages.

Réduire un album trop lourd

L'inverse : un album aux pages énormes (plus de 3200 px, ou plus de 3 Mo par page) peut être allégé avec Réduire le fichier (molette d'un tome), Réduire les tomes lourds (molette d'une série) ou la carte Albums trop lourds de la page Upscaling.

  • Choisissez la taille voulue, de 2000 à 3200 px.
  • Gardez l'original pour pouvoir revenir en arrière, ou supprimez-le pour gagner la place tout de suite.
  • Le fichier n'est remplacé que si la version réduite est plus légère.

10 Sécurité, comptes et thèmes

Connexion

Sans réglage, Bullarr est ouvert à tous sur votre réseau. Activez la connexion dans Configuration → Login : comptes locaux (identifiant et mot de passe) et, en option, un bouton SSO (OIDC). Les mots de passe et clés enregistrés sont chiffrés sur le disque.

Comptes et rôles

  • Admin : accès à tout.
  • Lecteur : parcourt, lit, télécharge, tient ses propres listes et demande des BD. Il ne voit pas les menus d'administration.
  • Les comptes SSO prennent leur rôle de leur groupe (admin_group) ; « Modifier » le force.
  • Inscription ouverte (option) : un lien « Créer un compte » apparaît sur la page de connexion, et l'admin valide chaque nouveau compte.
  • Contrôle parental : par lecteur, bibliothèques visibles et genres masqués, avec un préréglage « Enfant ».

Demandes de BD

Un lecteur demande une série depuis la page Demandes. L'admin l'accepte (en choisissant la bibliothèque) ou la refuse avec un motif dans Validation ; une option accepte tout automatiquement. Une demande acceptée ajoute la série et lance sa recherche.

Mon profil

Nom, e-mail, mot de passe, avatar, clé API personnelle et compte Komga. Pour Komga, Bullarr crée une clé à votre nom et ne garde pas le mot de passe ; sans Komga, Bullarr retient lui-même où vous en êtes. Connexions et changements de comptes sont dans Suivi → Historique.

Thèmes

Configuration → Thème : cinq palettes (Atelier, Ardoise, Sauge, Océan, Prune), en clair, en sombre ou en Système qui suit l'appareil. Le choix est propre à chaque navigateur. L'application Android a les mêmes palettes.
