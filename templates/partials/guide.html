Bullarr est un Sonarr pour les BD et les comics : il surveille les nouveautés, télécharge les albums qui manquent à vos séries et tient vos métadonnées à jour grâce à Bédéthèque. Cette page couvre l'installation, la configuration, les fonctions, le serveur MCP et l'application Android.

1 Installation

Bullarr tourne dans Docker, avec une base SQLite : rien d'autre à installer. Le guide complet est dans le README.

  1. Clonez le dépôt : git clone https://github.com/gwenvador/bullarr.git
  2. Copiez le modèle : cp docker-compose.example.yml docker-compose.yml
  3. Adaptez les volumes : le dossier de votre bibliothèque (/BD) et vos dossiers d'import.
  4. Créez le fichier .env avec une clé secrète : SECRET_KEY=... (une chaîne aléatoire longue, générée par exemple avec la commande ci-dessous).
  5. Démarrez : docker compose up -d, puis ouvrez http://localhost:4000.
python3 -c "import secrets; print(secrets.token_urlsafe(48))"

2 Premier démarrage

  1. Dans Configuration, ajoutez une bibliothèque en indiquant son dossier racine.
  2. Lancez le scan : Bullarr relève les séries et les tomes présents sur le disque.
  3. Rattachez chaque série à sa fiche Bédéthèque : résumé, auteur, éditeur, couverture et tomes attendus.
  4. La vérification de bibliothèque signale les séries sans métadonnées et les noms non standard.

3 Fonctions

📚 Bibliothèque

  • Trois vues : affiches, aperçu (une ligne par série) et tableau, avec tri et colonnes optionnelles.
  • Recherche du haut de page : titre, puis tags correspondants.
  • Fiche série : volumes possédés et manquants, badge de complétude, liens externes.

📡 Surveillance

Bullarr surveille les flux RSS et les nouveautés EBDZ et Telegram, reconnaît les nouveaux albums de vos séries et télécharge automatiquement ceux qui vous manquent.

🧭 Enrichir

Pour compléter votre collection : les indispensables, le Panthéon, les thèmes, le Top 100 et les sorties BDGest, ou toute la bibliographie d'un auteur.

📖 Lecteur de BD

Lecture des CBZ, CBR et PDF dans le navigateur : deux pages côte à côte, zoom, ajustement, bande de miniatures, plein écran. La touche ? affiche les raccourcis.

✏️ Renommage et métadonnées

Templates de nommage des fichiers et dossiers à partir des métadonnées Bédéthèque. Écriture du ComicInfo.xml dans les archives.

🕓 Historique

Imports et actions (renommage, suppression, déplacement) sont journalisés.

✨ Upscaling

Pastille LD / SD / HD et filtre Qualité dans la bibliothèque. Actions → Upscaling améliore les tomes en basse définition sur le serveur, le bouton HD du lecteur le fait à la volée. Détails dans la section Upscaling.

📑 Lectures

Suivi → Lectures liste l'historique de lecture du compte, avec export et import CSV. Un tome ou une série se marque comme lu depuis la bibliothèque.

4 Tags et listes

  • Tags : chaque série peut avoir des tags (thèmes, lieux, époques, noms). Ouvrez la fenêtre Tags de la fiche : + pour ajouter, × pour retirer.
  • La colonne Tags de la vue tableau affiche tous les tags, avec un filtre texte.
  • La recherche du haut de page trouve les séries par tag ; un clic sur un tag ouvre la bibliothèque filtrée sur ce tag.
  • Listes : « À lire plus tard » et « Favori » par série, depuis le menu Actions de la fiche. Un marque-page et un cœur apparaissent à côté du titre, et le menu Listes de la bibliothèque filtre sur l'une ou l'autre.

5 Import automatique

Bullarr surveille des dossiers de téléchargement : aMule, torrents, Telegram, sources web. Il reconnaît la série et le tome et convertit en CBZ si besoin. La page Import affiche les téléchargements en cours, avec leur progression, et permet de les mettre en pause ou en premier.

6 Bullarr et IA

Tags par IA

Dans Configuration → IA, choisissez un fournisseur. aiautotagging.com, proposé par défaut, est gratuit et ne demande ni clé ni compte. Vous pouvez aussi utiliser Claude (Anthropic), Gemini (Google), ChatGPT (OpenAI), OpenRouter (modèles gratuits compris), Groq ou un LLM local (Ollama, LM Studio, llama.cpp, vLLM) : collez votre clé API ou l'adresse du serveur local, puis « Tester ». La clé est chiffrée sur le disque de votre serveur ; ↻ lit la liste des modèles disponibles. Cochez des IA de secours : quand un fournisseur échoue (quota, panne, clé refusée), le suivant prend le relais. Les consignes envoyées à l'IA sont modifiables.

  • Créer les tags : pour les séries sans tags (leur nombre est affiché) ou pour toutes. L'IA lit le titre, les auteurs, le genre et le résumé et réutilise le vocabulaire existant. Les tags proposés s'ajoutent, rien n'est retiré.
  • Normaliser les tags : l'IA regroupe les tags qui veulent dire la même chose et propose un tag commun. Rien ne change avant votre validation.
  • Nouvelles séries : une option tague automatiquement chaque série ajoutée (Bédéthèque, import ou scan), dès son arrivée.
  • Historique : chaque traitement est journalisé avec les séries modifiées et les tags ajoutés.
Les appels sont facturés par le fournisseur choisi, sur votre clé. Seuls le titre, les auteurs, le genre, l’année, l’origine, le résumé et les tags sont envoyés, jamais les fichiers.

Serveur MCP

Bullarr expose un serveur MCP à l'adresse /mcp de votre instance. Il permet à Claude, ou à un autre assistant compatible, de chercher dans votre bibliothèque, de lire une fiche, de lister les tags et de les modifier, et de gérer les listes.

OutilRôle
search_seriesChercher par mots, tags et année.
get_seriesLire la fiche d'une série.
list_tagsLister les tags et le nombre de séries pour chacun.
set_series_tagsRemplacer les tags d'une série.
set_reading_listsGérer « à lire plus tard » et les favoris.

Activer le serveur

  1. Dans le .env de Bullarr, définissez BULLARR_MCP_TOKEN avec une chaîne aléatoire, puis redémarrez. Sans ce jeton, /mcp répond 503.
  2. Ajoutez le serveur dans Claude Code :
claude mcp add --transport http bullarr https://<votre-bullarr>/mcp \
  --header "Authorization: Bearer <BULLARR_MCP_TOKEN>"

Pour ChatGPT ou un autre client, indiquez la même adresse et le même en-tête Authorization: Bearer, si le client le permet.

Important : le serveur ne supprime rien et ne modifie aucun fichier. Il peut en revanche changer les tags et les listes. Ne partagez pas le jeton. L'adresse doit être joignable depuis le client : un assistant qui tourne sur internet ne peut pas atteindre une instance qui n'est accessible que sur votre réseau local.

7 API

Toutes les fonctions de l'interface sont accessibles par une API HTTP/JSON, avec une clé API envoyée dans l'en-tête X-Api-Key. La clé se crée dans Configuration, section Accès API. La liste de toutes les routes est sur la page /api/docs de votre instance. La documentation détaillée, avec des exemples curl et Python, est dans docs/API.md.

8 Application Android

L'application pilote Bullarr depuis le téléphone : bibliothèque, fiches, recherche, téléchargements, import et réglages. Elle lit vos albums en plein écran (webtoon, sens manga, double page en paysage, tome suivant), les copie sur le téléphone pour les lire hors ligne, et peut recevoir des notifications instantanées (imports, validations, tomes surveillés) via l'app ntfy.

  1. Installez-la depuis le dépôt F-Droid, avec Obtainium (ajoutez https://github.com/gwenvador/bullarr-android : l'APK vient des releases GitHub et les mises à jour sont signalées), ou téléchargez l'APK.
  2. Au premier lancement, indiquez l'adresse de votre serveur (par exemple http://192.168.1.10:4000) et votre clé API, puis « Tester » et « Enregistrer ».

9 Upscaling

Beaucoup de BD numérisées il y a longtemps ont des pages de 1600 px ou moins : elles sont floues sur un grand écran. L'upscaling les agrandit deux fois et les nettoie avec un réseau de neurones entraîné pour l'image dessinée : les traits restent nets, les aplats propres, et les artefacts JPEG disparaissent. Ces albums portent l'étiquette « Basse déf. » dans la bibliothèque. Le seuil (1600 px par défaut) se règle dans Configuration → Upscaling : 1200, 1600, 2000 ou 2400 px.

Bullarr reprend les huit modèles de l'application Android, convertis au format ONNX : Real-ESRGAN (rapide, général, général avec débruitage, qualité) et Real-CUGAN (SE et Pro, avec ou sans débruitage). Real-ESRGAN rapide est un bon choix par défaut ; Real-CUGAN donne des traits plus fins sur la BD franco-belge, en plus lent.

  • Dans le lecteur : le bouton HD améliore les pages à la volée sur la carte graphique de l'appareil (WebGPU). Rien n'est modifié sur le serveur. Le modèle est téléchargé une fois par navigateur, depuis le lecteur ou Configuration → Upscaling.
  • Sur le serveur : depuis la molette d'un tome ou d'une série (« Upscaler en HD », qui traite alors tous ses tomes en basse définition) ou la page Upscaling du menu Actions, qui liste les albums non HD, en traite plusieurs d'un coup (avec un modèle différent par album si besoin) et compare les huit modèles sur un extrait d'une de vos pages avant de choisir. Le serveur agrandit chaque page, puis remplace le fichier par sa version HD. L'original SD est gardé dans le dossier caché .bullarr-sd-backup à la racine de la bibliothèque, et « Restaurer la version SD » le remet en place.

À l'inverse, réduire un fichier trop lourd : « Réduire le fichier » (molette d'un tome), « Réduire les tomes lourds » (molette d'une série) ou la carte Albums trop lourds de la page Upscaling (pages de plus de 3200 px ou plus de 3 Mo par page en moyenne). On choisit la définition voulue (2000 à 3200 px, toujours au-dessus du seuil de basse définition) et si l'original est gardé (restaurable, la place n'est gagnée qu'en le supprimant ensuite) ou supprimé tout de suite, une fois la version réduite vérifiée. Les pages sont réduites et réencodées en JPEG de bonne qualité ; le fichier n'est remplacé que s'il devient plus léger.

Comment ça marche : chaque page est découpée en tuiles de 256 px qui se chevauchent un peu, chaque tuile passe dans le modèle, puis les tuiles sont recollées sans couture visible. Sur le serveur le calcul se fait sur le processeur, un tome à la fois : comptez de quelques minutes à plus d'une heure par album selon le modèle.

10 Sécurité et authentification

  • Les secrets (mots de passe, clés API) sont chiffrés sur disque.
  • L'authentification est facultative et désactivée par défaut. Activez-la dans Configuration → Login : comptes locaux (identifiant et mot de passe), avec en option un bouton SSO OIDC.
  • Le serveur MCP et l'API utilisent chacun leur propre jeton ou clé, distincts de la session du navigateur.

Comptes, demandes et contrôle parental

  • Utilisateurs et rôles (Configuration → Login) : comptes locaux à créer, modifier ou supprimer ; comptes OIDC avec un rôle par groupe (admin_group) ou forcé par compte.
  • Lecteurs : ils parcourent, lisent et téléchargent, ont leurs propres listes « À lire plus tard » et Favoris, et demandent des BD depuis la page Demandes. Les menus d'administration leur sont masqués.
  • Demandes de BD : elles attendent votre validation dans la page Validation (bibliothèque au choix, refus avec motif), ou sont validées automatiquement si vous cochez l'option. Une fois validée, la série est ajoutée et sa recherche lancée.
  • Inscription ouverte (option) : un lien « Créer un compte » sur la page de connexion ; le compte reste en attente jusqu'à ce qu'un admin le valide.
  • Contrôle parental : bibliothèques visibles et genres masqués par lecteur, avec un préréglage « Enfant ».
  • Mon profil : nom, e-mail, mot de passe, avatar (photo ou avatar proposé) et compte Komga personnel. Bullarr crée une clé API Komga à votre nom et ne garde jamais le mot de passe ; sans compte Komga, votre avancement de lecture est gardé par Bullarr.
  • Historique : onglets Utilisateurs (connexions, comptes, rôles, accès) et Demandes.

Thèmes

Configuration → Thème propose cinq palettes, Atelier, Ardoise, Sauge, Océan et Prune, chacune en clair, en sombre ou en mode Système, qui suit le réglage clair ou sombre de l'appareil et change en direct. Le choix est gardé dans le navigateur. L'application Android a les mêmes palettes dans ses réglages.
