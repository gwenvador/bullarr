Configurez la connexion à votre client aMule ou eMule pour ajouter des téléchargements depuis l'interface.

📖 Aide à la configuration

Comment configurer aMule sur Linux ?
  1. Ouvrez aMule
  2. Allez dans Préférences > Connexions à distance
  3. Cochez "Activer les External Connections"
  4. Définissez un mot de passe EC
  5. Notez le port (défaut: 4712)
  6. Installez amule-utils : sudo apt install amule-utils
  7. Redémarrez aMule
Comment configurer eMule sur Windows ?
  1. Ouvrez eMule
  2. Allez dans Options > Interface Web
  3. Cochez "Activer le serveur web"
  4. Définissez un mot de passe
  5. Notez le port (défaut: 4711)
  6. Redémarrez eMule
La connexion échoue, que faire ?
  • ✅ Vérifiez que aMule/eMule est bien démarré
  • ✅ Vérifiez le mot de passe EC
  • ✅ Vérifiez que le port EC est correct
  • ✅ Vérifiez que le pare-feu n'est pas bloquant
  • ✅ Pour aMule : vérifiez que amule-utils est installé
  • ✅ Testez avec amulecmd -h 127.0.0.1 -P votreMotDePasse -c status

Où trouver le code du forum (fid) ?
  1. Rendez-vous sur ebdz.net/forum
  2. Ouvrez la catégorie qui vous intéresse (ex : BD, Comics…)
  3. Dans l'URL du navigateur, vous verrez un paramètre comme fid=29

Combien de pages le scraper parcourt-il ?

Le scraper s'arrête tout seul dès qu'il retrouve un sujet déjà connu n'ayant reçu aucune nouvelle réponse depuis le dernier passage - les sujets du forum étant classés par activité récente, tout ce qui suit est nécessairement déjà à jour. Aucune limite de pages à régler à la main.

Configuration Prowlarr

Configurez la connexion à votre serveur Prowlarr pour intégrer les indexeurs et améliorer vos recherches de contenu.

Adresse complète du serveur Prowlarr (avec http:// ou https://)
Port d'accès à Prowlarr (défaut: 9696)
Clé API disponible dans les paramètres Prowlarr > Paramètres > Général > Sécurité

🔎 Indexeurs à utiliser

Cliquez sur "Récupérer les indexeurs" pour charger la liste depuis Prowlarr

📖 Aide à la configuration

Où trouver ma clé API Prowlarr ?
  1. Ouvrez Prowlarr dans votre navigateur
  2. Allez dans Paramètres (⚙️) > Général
  3. Faites défiler jusqu'à Sécurité
  4. Vous trouvez le champ Clé API
  5. Copiez la clé et collez-la dans le formulaire ci-dessus
Comment accéder à Prowlarr depuis une autre machine ?
  • Si Prowlarr est sur la même machine : http://127.0.0.1:9696
  • Si Prowlarr est sur une autre machine du réseau : http://192.168.1.100:9696 (remplacez par l'IP)
  • Assurez-vous que le port 9696 (ou celui configuré) est accessible
  • En HTTPS, utilisez https:// au lieu de http://
La connexion échoue, que faire ?
  • ✅ Vérifiez que Prowlarr est bien démarré
  • ✅ Vérifiez que l'URL est correcte (avec http:// ou https://)
  • ✅ Vérifiez que la clé API est correcte
  • ✅ Vérifiez que le port est accessible (pare-feu)
  • ✅ Essayez d'accéder à Prowlarr dans votre navigateur pour vérifier que ça fonctionne

Configuration qBittorrent

Configurez la connexion à votre serveur qBittorrent pour ajouter des torrents depuis l'interface.

Adresse du serveur qBittorrent (sans :port ni http://stream)
Port du Web UI de qBittorrent (défaut: 8080)
Nom d'utilisateur du Web UI (optionnel)
Mot de passe du Web UI (optionnel)
La catégorie utilisée par défaut pour les torrents ajoutés (chargée depuis qBittorrent)

📖 Aide à la configuration

Comment accéder au Web UI de qBittorrent ?
  1. Ouvrez qBittorrent sur votre ordinateur ou serveur
  2. Allez dans Outils > Options
  3. Sélectionnez Web UI dans le menu de gauche
  4. Cochez "Activer le serveur Web"
  5. Notez le Port (défaut: 8080)
  6. Définissez un nom d'utilisateur et un mot de passe si souhaité
  7. Cliquez OK et redémarrez qBittorrent
Comment accéder à qBittorrent depuis une autre machine ?
  • Si qBittorrent est sur la même machine : http://localhost:8080 ou http://127.0.0.1:8080
  • Si qBittorrent est sur une autre machine du réseau : http://192.168.1.100:8080 (remplacez par l'IP)
  • Assurez-vous que le port est accessible (pare-feu)
  • En HTTPS, utilisez https:// au lieu de http://
La connexion échoue, que faire ?
  • ✅ Vérifiez que qBittorrent est bien démarré
  • ✅ Vérifiez que le Web UI est activé dans les options
  • ✅ Vérifiez que l'URL et le port sont corrects
  • ✅ Vérifiez les identifiants (si configurés)
  • ✅ Vérifiez que le port est accessible (pare-feu)
  • ✅ Essayez d'accéder au Web UI dans votre navigateur pour vérifier

📖 Aide à la configuration

Comment créer un bot et obtenir son jeton ?
  1. Ouvrez une conversation avec @BotFather sur Telegram
  2. Envoyez la commande /newbot et suivez les instructions
  3. @BotFather vous donne un jeton (ex: 123456789:AAExemple...) - copiez-le dans le formulaire ci-dessus
Comment trouver mon Chat ID ?
  • Démarrez une conversation avec votre bot (cherchez-le par son nom, cliquez sur "Démarrer")
  • Envoyez-lui n'importe quel message
  • Ouvrez https://api.telegram.org/bot<VOTRE_JETON>/getUpdates dans un navigateur
  • Cherchez "chat":{"id":...} dans la réponse JSON - c'est votre Chat ID

      ✏️ Format de renommage

      Tags disponibles

      Tag Explication Exemple
      <series> Titre de la série Dans Les Forêts De Bambous
      <number2> Numéro de tome, complété par des zéros sur 2 chiffres (jamais tronqué: un numéro à 3 chiffres reste sur 3 chiffres) 01, 12, 123
      <title> Titre du tome, lu dans le ComicInfo.xml (balise <Title>) Pandas Dans La Brume
      <year> Année du tome (ComicInfo <Year>, ou l'année détectée sur le fichier à défaut) 2010
      <quality> Tag de résolution/scan détecté sur le fichier d'origine - absent si le fichier n'en portait pas Digital-1734
      <group> Groupe de scan/release détecté sur le fichier d'origine - absent si le fichier n'en portait pas NEO RIP-Club
      <univers> Univers Bédéthèque de la série (détecté via ses "Séries liées") - absent si la série n'appartient à aucun univers connu Thorgal

      Blocs optionnels

      Un texte entre accolades { ... } est entièrement omis (y compris les espaces/tirets qu'il contient) si l'un des tags qu'il contient n'a pas de valeur pour ce fichier - pas besoin de séparateur "orphelin" (ex: " - #" tout seul) quand l'information manque.

      Format Avec <number2> = 01 Sans <number2>
      { - #<number2>} " - #01" "" (rien)
      Tags disponibles: <series>, <number2>, <title>, <year>, <quality>, <group>, <univers>
      Utilisé uniquement pour les séries marquées « One shot ». Le titre du volume est facultatif. Tags disponibles: <series>, <number2>, <title>, <year>, <quality>, <group>, <univers>
