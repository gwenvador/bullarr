Documentation

Bullarr est un gestionnaire de bibliothèque de BD francophone. Cette page couvre l'installation, la configuration, les fonctions, le serveur MCP et l'application Android.

1. Installation

Bullarr tourne dans Docker, avec une base SQLite : rien d'autre à installer. Le guide complet est dans le README.

  1. Clonez le dépôt : git clone https://github.com/gwenvador/bullarr.git
  2. Copiez le modèle : cp docker-compose.example.yml docker-compose.yml
  3. Adaptez les volumes : le dossier de votre bibliothèque (/BD) et vos dossiers d'import.
  4. Créez le fichier .env avec une clé secrète : SECRET_KEY=... (une chaîne aléatoire longue).
  5. Démarrez : docker compose up -d, puis ouvrez http://localhost:4000.
python3 -c "import secrets; print(secrets.token_urlsafe(48))"

2. Premier démarrage

  1. Dans Configuration, ajoutez une bibliothèque en indiquant son dossier racine.
  2. Lancez le scan : Bullarr relève les séries et les tomes présents sur le disque.
  3. Rattachez chaque série à sa fiche Bédéthèque : résumé, auteur, éditeur, couverture et tomes attendus.
  4. La vérification de bibliothèque signale les séries sans métadonnées et les noms non standard.

3. Fonctions

Bibliothèque

  • Trois vues : affiches, aperçu (une ligne par série) et tableau, avec tri et colonnes optionnelles.
  • Recherche du haut de page : titre, puis tags correspondants.
  • Fiche série : volumes possédés et manquants, badge de complétude, liens externes.

Tomes manquants

Bullarr compare les tomes attendus à ceux possédés, et peut lancer la recherche et le téléchargement sur les sources configurées.

Lecteur de BD

Lecture des CBZ, CBR et PDF dans le navigateur : deux pages côte à côte, zoom, ajustement, bande de miniatures, plein écran. La touche ? affiche les raccourcis.

Renommage et métadonnées

Templates de nommage des fichiers et dossiers à partir des métadonnées Bédéthèque. Écriture du ComicInfo.xml dans les archives.

Historique

Imports et actions (renommage, suppression, déplacement) sont journalisés, avec annulation pour les imports.

4. Tags et listes

  • Tags : chaque série peut avoir des tags (thèmes, lieux, époques, noms). Ouvrez la fenêtre Tags de la fiche : + pour ajouter, × pour retirer.
  • La colonne Tags de la vue tableau affiche tous les tags, avec un filtre texte.
  • La recherche du haut de page trouve les séries par tag ; un clic sur un tag ouvre la bibliothèque filtrée sur ce tag.
  • Listes : « À lire plus tard » et « Favori » par série, depuis le menu Actions de la fiche. Les icônes 📚 et ⭐ apparaissent à côté du titre, et le menu Listes de la bibliothèque filtre sur l'une ou l'autre.

5. Import automatique

Bullarr surveille des dossiers de téléchargement : aMule, torrents, Telegram, sources web. Il reconnaît la série et le tome, convertit en CBZ si besoin, et garde un historique annulable. La page Import affiche les téléchargements en cours, avec leur progression, et permet de les mettre en pause ou en premier.

6. Bullarr et AI (serveur MCP)

Bullarr expose un serveur MCP à l'adresse /mcp de votre instance. Il permet à Claude, ou à un autre assistant compatible, de chercher dans votre bibliothèque, de lire une fiche, de lister les tags et de les modifier, et de gérer les listes.

OutilRôle
search_seriesChercher par mots, tags et année.
get_seriesLire la fiche d'une série.
list_tagsLister les tags et le nombre de séries pour chacun.
set_series_tagsRemplacer les tags d'une série.
set_reading_listsGérer « à lire plus tard » et les favoris.

Activer le serveur

  1. Dans le .env de Bullarr, définissez BULLARR_MCP_TOKEN avec une chaîne aléatoire, puis redémarrez. Sans ce jeton, /mcp répond 503.
  2. Ajoutez le serveur dans Claude Code :
claude mcp add --transport http bullarr https://<votre-bullarr>/mcp \
  --header "Authorization: Bearer <BULLARR_MCP_TOKEN>"

Pour ChatGPT ou un autre client, indiquez la même adresse et le même en-tête Authorization: Bearer, si le client le permet.

Important : le serveur ne supprime rien et ne modifie aucun fichier. Il peut en revanche changer les tags et les listes. Ne partagez pas le jeton. L'adresse doit être joignable depuis le client : un assistant qui tourne sur internet ne peut pas atteindre une instance qui n'est accessible que sur votre réseau local.

7. API

Toutes les fonctions de l'interface sont accessibles par une API HTTP/JSON, avec une clé API envoyée dans l'en-tête X-Api-Key. La clé se crée dans Configuration, section Accès API. La documentation détaillée, avec des exemples curl et Python, est dans docs/API.md.

8. Application Android

L'application pilote Bullarr depuis le téléphone : bibliothèque, fiches, recherche, téléchargements, import et réglages.

  1. Installez-la depuis le dépôt F-Droid, ou téléchargez l'APK.
  2. Au premier lancement, indiquez l'adresse de votre serveur (par exemple http://192.168.1.10:4000) et votre clé API, puis « Tester » et « Enregistrer ».

9. Sécurité et authentification

  • Les secrets (mots de passe, clés API) sont chiffrés sur disque.
  • L'authentification est facultative et désactivée par défaut. Vous pouvez activer un identifiant et un mot de passe, un SSO OIDC, ou les deux, dans Configuration → Login.
  • Le serveur MCP et l'API utilisent chacun leur propre jeton ou clé, distincts de la session du navigateur.
